# Aditya Shashikant Kamble — Personal Portfolio

My personal portfolio website showcasing my experience, education, projects, skills, and hackathon achievements.

Built with **Next.js**, **React**, **TypeScript**, **Tailwind CSS**, **Shadcn/UI**, **Framer Motion**, and **Magic UI**.

## 🚀 Live Demo

You can view the live site here: [aadii-personal-portfolio.vercel.app](https://aadii-personal-portfolio.vercel.app/)

## 🛠️ Features

- **Personal Details & Summary:** Introduction, professional titles, and brief summary.
- **Work Experience & Internships:** Mapped internships at Codomax Digital Solutions and Asterisc Technocart.
- **Education Milestones:** Mapped degree, junior college, and high school timelines.
- **Featured Projects:** Showcases core projects (LearnSphere, Lifeline, ArcoCafe, Hackathon Matcher, Cascade Simulator) with live links, repositories, and screenshots.
- **Skill Badges:** Mapped with custom SVG icons (Svelte, Supabase, MySQL, HTML5, CSS3, JS, Figma, Vercel, Git, etc.).
- **Hackathons Timeline:** Details of state-level events (CODEX, TECHXPLORE, CODEFORGE) participated in Nagpur.
- **Clean Layout:** Removed original blog configurations and set up direct contact forms to LinkedIn and Email.

## 💻 Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS, Shadcn/UI, Magic UI, Framer Motion
- **Languages:** TypeScript, JavaScript, HTML5, CSS3
- **Tools:** Git, VS Code, Figma, Postman, Vercel

## ⚙️ Getting Started Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/adityakamble69/portfolio.git
   ```

2. Move into the directory:
   ```bash
   cd portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the local development server:
   ```bash
   npm run dev
   ```

5. Open the configuration file at `./src/data/resume.tsx` to customize the details.
